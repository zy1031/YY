## 1. 系统登录

### 1.1 访问系统

在浏览器中访问：`http://localhost:5173`

### 1.2 登录

1. 输入**用户名**和**密码**
2. 点击**登录**按钮
3. 登录成功后自动跳转到系统首页

### 1.3 注册新账号

1. 点击登录页下方「立即注册」
2. 填写用户名、密码、邮箱
3. 点击注册，成功后返回登录页

> 用户名长度 3-50 个字符，密码长度 6-100 个字符

## 3. 图片检测

### 3.1 基本流程

1. 点击左侧菜单「图片检测」
2. 点击上传区域或拖拽图片文件（支持 JPG/PNG/WEBP）
3. 选择动物类型（可选）
4. 点击「开始检测」按钮
5. 等待检测完成，查看结果

### 3.2 检测结果说明

| 状态 | 说明 | 颜色标注 |
|------|------|----------|
| 正常 | 动物健康状态良好 | 绿色边框 |
| 可疑 | 存在轻微异常，需观察 | 黄色/橙色边框 |
| 异常 | 存在明显健康问题 | 红色边框 |

### 3.3 生成报告

检测完成后，点击「生成报告」按钮，系统将使用 AI 自动生成健康分析报告。

### 3.4 注意事项

- 图片清晰度越高，检测准确率越高
- 建议图片中动物占画面面积 30% 以上
- 支持一张图片中包含多头动物
- 最大文件大小：100MB

## 4. 视频检测

### 4.1 基本流程

1. 点击「视频检测」
2. 上传视频文件（支持 MP4/AVI）
3. 点击「开始检测」
4. 系统在后台异步处理，可通过进度条查看进度
5. 检测完成后查看逐帧分析结果

### 4.2 视频检测特性

- **BoT-SORT 跟踪**：自动为每头动物分配唯一跟踪 ID，跨帧持续追踪
- **逐帧分析**：每帧独立检测，汇总整段视频健康状况
- **跟踪轨迹**：可查看每头动物在视频中的运动轨迹

### 4.3 注意事项

- 视频时长建议不超过 5 分钟
- 检测时间约为视频时长的 1-3 倍（取决于服务器性能）
- 检测过程中可以离开页面，结果会保存在检测记录中

## 5. 实时摄像头检测

### 5.1 基本流程

1. 点击「实时检测」
2. 确保摄像头设备已连接
3. 选择摄像头或输入 RTSP 流地址
4. 点击「开始检测」
5. 实时查看检测结果（帧率 ≥ 10 FPS）
6. 点击「停止检测」结束

### 5.2 实时检测特性

- **实时推流**：通过 WebSocket 实时推送检测结果
- **目标跟踪**：持续追踪画面中的每头动物
- **异常告警**：发现异常时界面高亮提示

### 5.3 RTSP 流格式

```
rtsp://username:password@ip:port/stream
```

## 6. 检测记录

### 6.1 查看记录列表

检测记录页面展示所有历史检测，支持以下筛选：

| 筛选项 | 说明 |
|--------|------|
| 检测类型 | 图片 / 视频 / 摄像头 |
| 检测状态 | 处理中 / 已完成 / 失败 |
| 日期范围 | 按创建时间筛选 |

### 6.2 查看详情

点击任意记录的「详情」按钮，可查看：
- 原始文件和标注结果图
- 每个检测目标的详细信息
- 健康状态分布
- 关联的 AI 报告

### 6.3 删除记录

点击「删除」按钮，确认后删除检测记录及关联文件。

> ⚠️ 删除后不可恢复，请谨慎操作

## 10. 模型管理

### 10.1 查看可用模型

模型管理页展示所有已配置的检测模型及当前激活模型。

### 10.2 切换模型

1. 在模型列表中找到目标模型
2. 点击「切换为当前模型」
3. 后续检测将使用该模型

### 10.3 调整模型参数

| 参数 | 说明 | 推荐范围 |
|------|------|----------|
| 置信度阈值 | 低于此值的检测结果将被过滤 | 0.3 - 0.7 |
| IOU 阈值 | 控制重叠框的合并程度 | 0.3 - 0.6 |

拖动滑块调整后点击「保存参数」生效。

## 12. 常见问题

**Q：检测速度很慢怎么办？**

A：图片检测建议使用 GPU 服务器。无 GPU 时系统自动使用 CPU 推理，速度较慢属正常。

**Q：检测结果都是「mock 数据」？**

A：系统未配置模型文件时自动使用 mock 模式生成模拟结果。请联系管理员配置真实 YOLO 模型。

**Q：视频检测一直「处理中」？**

A：视频检测为异步处理，长视频需要等待较长时间。可刷新页面查看最新进度。

**Q：摄像头无法连接？**

A：请确认摄像头设备已连接，浏览器已授权摄像头权限，或 RTSP 地址填写正确。

**Q：PDF 下载后发现是 HTML 文件？**

A：服务器未安装 reportlab 库，系统自动降级为 HTML 格式，可在浏览器中打印为 PDF。

**Q：如何退出登录？**

A：点击右上角用户名，选择「退出登录」。
